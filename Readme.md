🙋‍♂️ Sobre mim

Estudante de Ciência da Computação (5º período ) com sólido interesse em engenharia de software, análise de dados e arquitetura de sistemas. Dedico-me ao aprimoramento contínuo em lógica de programação e resolução de problemas complexos, buscando aplicar as melhores práticas de desenvolvimento para criar soluções eficientes e escaláveis. Tenho foco em desenvolvimento backend, automação de processos e integração de sistemas com bancos de dados. Atualmente, resido em Brasília – DF.




📂 Principais Projetos

•
🚀 Projeto Python Gemini API: Desenvolvimento de API robusta utilizando FastAPI para integração e processamento de dados via Inteligência Artificial.

•
📉 Estrutura de Dados em C: Implementação de algoritmos otimizados para consulta e monitoramento de sensores, focando em performance e gerenciamento de memória.

•
🏦 Sistema Bancário Python: Aplicação completa integrando Python, Tkinter para interface gráfica e MySQL para persistência de dados e operações CRUD seguras.

☕ Sistema Bancário Java: Desenvolvimento orientado a objetos (POO) aplicando conceitos de herança, polimorfismo e encapsulamento para gestão financeira.
